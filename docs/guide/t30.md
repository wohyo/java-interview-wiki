# 30. Spring AOP

**Q：AOP 的实现原理？**

通过动态代理（JDK 代理或 CGLIB 代理）在目标方法前后织入增强逻辑

通知类型：@Before / @After / @Around / @AfterReturning / @AfterThrowing

应用场景：事务管理（@Transactional）、日志、权限、缓存

**🔥 Q：@Transactional 失效的场景？**

1. 同类方法内调用：`A ``方法调`` this.B ``方法` → 不走代理

解决：注入自身 `@Autowired SelfClass self;` 或用 `AopContext.currentProxy()`

2. 方法不是 public：AOP 默认只增强 public 方法

3. 异常被 catch：事务方法内 try-catch 了异常但没抛出

4. rollbackFor 没指定：默认只回滚 RuntimeException 和 Error，Checked Exception 不回滚

5. 传播行为设置不当
