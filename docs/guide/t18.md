# 18. JVM 调优

**Q：常用 JVM 调优参数？**

```
# 堆
-Xms4g -Xmx4g                  # 堆初始/最大（生产设相同，避免扩容抖动）
-Xmn2g                         # 新生代大小
-XX:SurvivorRatio=8            # Eden:Survivor = 8:1
```

```
# 元空间
-XX:MetaspaceSize=256m         # 元空间初始
-XX:MaxMetaspaceSize=256m      # 最大
```

```
# GC 选择
-XX:+UseG1GC                   # 使用 G1（JDK 9+ 默认）
-XX:MaxGCPauseMillis=200       # 目标停顿时间
```

```
# OOM
-XX:+HeapDumpOnOutOfMemoryError # OOM 时 dump 堆
-XX:HeapDumpPath=/tmp/dump.hprof
```

```
# GC 日志
-Xlog:gc*                      # JDK 9+ 统一日志
```

**🔥 Q：CPU 100% 怎么排查？**

1. `top` → 找到 CPU 最高的 Java 进程 PID

2. `top -H -p PID` → 找到 CPU 最高的线程 TID

```
3. printf "%x\n" TID → 转为十六进制
```

```
4. jstack PID | grep -A 30 "nid=0xHEX" → 定位到代码行
```

5. 看是 GC 线程（频繁 GC）、业务线程（死循环）、还是锁竞争（大量 BLOCKED）
