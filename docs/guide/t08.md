# 8. ArrayList vs LinkedList

**Q：两者的区别与使用场景？**

|  | ArrayList | LinkedList |
| --- | --- | --- |
| 底层 | Object[] 数组 | 双向链表（JDK 6 是循环链表，7+ 去掉了） |
| 随机访问 get(i) | O(1) | O(n) 从头/尾遍历 |
| 尾部 add | O(1) 均摊（偶尔扩容） | O(1) |
| 指定位置add/remove | O(n) 移动元素 | O(n) 先遍历到位置，再 O(1) 改指针 |
| 内存 | 连续空间，会预分配扩容 | 不连续，每个 Node 存 prev/next/item 三指针 |
| 适用 | 随机读多、尾部追加 | 频繁头尾插入删除、队列场景 |

**🔥 Q：ArrayList 扩容细节？**

默认大小 10（懒加载，JDK 8 第一次 add 时才创建）

扩容公式：newCapacity = oldCapacity + (oldCapacity &gt;&gt; 1) → 1.5 倍

`Arrays.copyOf()` 调用 `System.arraycopy()` （native 方法，C 层面内存拷贝）

最大容量：`Integer.MAX_VALUE - 8` （-8 是因为部分 JVM 在数组头部存 header）
