# 8. ArrayList vs LinkedList

**Q：两者的区别与使用场景？**

底层结构决定了后面所有差异：ArrayList 是 `Object[]` 数组，LinkedList 是双向链表（JDK 6 是循环链表，7+ 去掉了）。

随机访问 get(i)：数组按下标直接定位，O(1)；链表必须从头或尾顺着指针走过去，O(n)。

尾部追加：两者都是 O(1)，ArrayList 是均摊 O(1)——数组满了要扩容拷贝一次。

指定位置的插入/删除：两者都是 O(n)，但原因不同。ArrayList 要把后面的元素整体移动腾出位置；LinkedList 是先遍历到那个位置 O(n)，改指针本身只要 O(1)。所以"链表插入快"这句话只在已经拿到节点引用时才成立。

内存：ArrayList 占连续空间，还会按 1.5 倍预分配，尾部可能有容量浪费；LinkedList 每个 Node 除了元素本身还要存 prev、next 两个指针，加上对象头，单个元素的实际开销更大，而且内存不连续、缓存友好性差。

适用：随机读多、尾部追加用 ArrayList；频繁在头尾插入删除、当队列用才考虑 LinkedList。实际上 LinkedList 很少是赢家——头尾操作用 ArrayDeque 更好，需要下标访问和内存局部性时 ArrayList 又碾压链表。

**🔥 Q：ArrayList 扩容细节？**

默认大小 10（懒加载，JDK 8 第一次 add 时才创建）

扩容公式：newCapacity = oldCapacity + (oldCapacity &gt;&gt; 1) → 1.5 倍

`Arrays.copyOf()` 调用 `System.arraycopy()` （native 方法，C 层面内存拷贝）

最大容量：`Integer.MAX_VALUE - 8` （-8 是因为部分 JVM 在数组头部存 header）
