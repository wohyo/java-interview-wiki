# 2. == 与 equals()、hashCode()

**Q：== 和 equals() 的区别？**

`==` ：比较内存地址（基本类型比较数值）

`equals()` ：Object 默认等同 `==` ，但 String、Integer 等重写为比较内容

**⚡ Q：重写 equals() 为什么要重写 hashCode()？不重写会怎样？**

约定：两个对象 equals 相等 → hashCode 必须相等。反之不要求

后果：不重写 hashCode 会导致 HashMap/HashSet 等散列集合出 Bug

```
Map<Student, String> map = new HashMap<>();
map.put(new Student("张三"), "A班");
map.get(new Student("张三"));  // → null！因为两个对象 hashCode 不同，定位到不同桶
```

原理：HashMap 先通过 hashCode 定位桶，再在桶内用 equals 判断。hashCode 不同 → 直接找不到

**⚡ Q：hashCode 碰撞怎么处理？**

不同对象 hashCode 相同 → HashMap 中通过链表/红黑树处理

链表长度 ≥8 且数组长度 ≥64 → 转红黑树，提高查找效率
