# 9. 线程状态与生命周期

**Q：线程有哪 6 种状态？**

```
NEW（新建） → RUNNABLE（就绪/运行） → BLOCKED（阻塞，等锁） → WAITING（无限期等待：join、park） → TIMED_WAITING（超时等待：sleep、wait(timeout)） → TERMINATED（终止）
```

**⚡ Q：sleep() 和 wait() 的区别？**

最本质的差别是是否释放锁。

sleep() 是 Thread 的静态方法，让当前线程暂停指定时间，但它抱着锁睡觉——synchronized 块里调用 sleep 不会释放监视器，其他线程照样进不来。到时间或者被 interrupt 就醒。调用位置没有任何限制。

wait() 是 Object 的实例方法，它释放监视器锁，把自己交给该对象的等待队列，其他线程就能进入同步块。唤醒靠 notify()/notifyAll()，或者带超时的 wait(timeout) 自己到期。前提是当前线程必须持有这个对象的锁，也就是只能在 synchronized 块/方法里调用，否则抛 IllegalMonitorStateException。

记忆点：sleep 是"带着锁休息"，wait 是"交出锁等人叫醒"。所以 wait 醒来后还要重新竞争锁，而且必须写在循环里重新判断条件，防止虚假唤醒。
