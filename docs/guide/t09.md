# 9. 线程状态与生命周期

**Q：线程有哪 6 种状态？**

```
NEW（新建） → RUNNABLE（就绪/运行） → BLOCKED（阻塞，等锁） → WAITING（无限期等待：join、park） → TIMED_WAITING（超时等待：sleep、wait(timeout)） → TERMINATED（终止）
```

**⚡ Q：sleep() 和 wait() 的区别？**

|  | sleep() | wait() |
| --- | --- | --- |
| 所属 | Thread 静态方法 | Object 实例方法 |
| 锁释放 | ❌ 不释放锁 | ✅ 释放锁 |
| 被唤醒 | 时间到 / interrupt | notify / notifyAll / 超时 |
| 调用前提 | 任意位置 | 必须在 synchronized 块内 |
