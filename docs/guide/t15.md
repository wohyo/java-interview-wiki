# 15. 运行时数据区

**Q：JVM 运行时内存区域？哪些线程私有？哪些共享？**

```
线程私有：程序计数器 | 虚拟机栈 | 本地方法栈
线程共享：堆 (Heap) | 元空间/方法区 (Metaspace)
```

| 区域 | 作用 | 异常 |
| --- | --- | --- |
| 程序计数器 | 记录当前线程执行的字节码行号 | 无 |
| 虚拟机栈 | 每个方法对应一个栈帧（局部变量表、操作数栈、动态链接、返回地址） | StackOverflowError /OOM |
| 本地方法栈 | 调用 native 方法 | StackOverflowError /OOM |
| 堆 | 对象实例、数组 | OOM |
| 方法区（元空间） | 类信息、常量、静态变量、JIT 代码 | OOM |

**🔥 Q：Java 8 为什么用 Metaspace 替换 PermGen？**

1. PermGen 有固定上限：`-XX:MaxPermSize` ，容易 OOM（尤其是热部署、大量动态生成类）

2. Metaspace 使用本地内存（Native Memory）：默认无上限（受 OS 内存限制），不易 OOM

3. GC 效率：PermGen 的 GC 扫描效率低，Metaspace 更灵活

4. 字符串常量池移动：JDK 7 将字符串常量池移到堆；JDK 8 彻底移除 PermGen
