# 24. Redis 跳表

**Q：Redis ZSET 的底层实现？跳表是什么？**

ZSET（有序集合）底层是 压缩列表（元素少时） 或 跳表 + 哈希表（元素多时）

跳表（Skip List）：多层链表，上层是下层的"快速通道"

```
Level 3: 1 ----------------→ 9
Level 2: 1 -----→ 5 -----→ 9
Level 1: 1 → 3 → 5 → 7 → 9 (底层全量链表)
```

**🔥 Q：为什么 Redis 用跳表而不是平衡树？**

1. 范围查询高效：跳表底层是链表，找到起点后直接遍历。平衡树需要中序遍历

2. 实现简单：跳表代码量 ~200 行，平衡树插入/删除的旋转/变色复杂得多

3. 内存可控：跳表通过概率生成层数，平均 O(log n)。平衡树每个节点固定两个指针

4. Redis ZSET 是双向链表：支持 `ZREVRANGE` 倒序遍历（RediSearch 中也用到）
