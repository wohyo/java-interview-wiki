# 3. 泛型

**Q：Java 泛型是编译期还是运行期？类型擦除是什么？**

编译期特性，编译后字节码中泛型类型信息被擦除

`List&lt;String&gt;` → `List` ，插入元素处插入 `checkcast` 字节码检查

类型参数替换为边界类型（无边界则替换为 Object）

**🔥 Q：既然擦除了，那 List&lt;String&gt; 和 List&lt;Integer&gt; 的 class 文件相同吗？**

运行时相同：`list.getClass() == list2.getClass()` → true

但通过反射获取 `Method.getGenericParameterTypes()` 可以拿到泛型签名（存在 Signature 属性中）

**🔥 Q：Java 为什么选择类型擦除而不是 C# 那样的具现化泛型？**

兼容性：擦除泛型可以兼容已有的非泛化类库（ArrayList 不需要重新实现）

迁移兼容：Java 5 引入泛型时，已有大量旧代码。擦除使泛化代码和非泛化代码可以互操作

代价：运行时无法获取泛型类型，灵活性降低（如 `new T()` 不允许）
