# 22. 覆盖索引、索引下推

**Q：覆盖索引和最左前缀原则？**

覆盖索引：索引中已包含查询所需的所有列，不需要回表。`EXPLAIN` 的 Extra 列为 `Using index`

最左前缀：联合索引 `(a, b, c)` 有效查询为 `a` / `a,b` / `a,b,c` 。跳过的列无法利用索引

**🔥 Q：索引下推（Index Condition Pushdown, ICP）是什么？**

MySQL 5.6+ 优化，将 WHERE 条件中可以用到索引的过滤条件推给存储引擎层在索引遍历时提前过滤

无 ICP：Server 层对存储引擎返回的行逐一判断 WHERE

有 ICP：存储引擎在读取索引时就判断条件，不满足的不回表（减少回表次数）
