# 14. CAS 与 ABA

**Q：CAS 原理？**

Compare And Swap，CPU 原子指令

三个操作数：内存地址 V、期望值 A、新值 B

V == A → V = B，否则重试（自旋）

Java 实现：`Unsafe.compareAndSwapInt(this, valueOffset, expect, update)`

应用：AtomicInteger、synchronized 锁升级、ConcurrentHashMap

**🔥 Q：ABA 问题是什么？怎么解决？**

ABA：值从 A→B→A，CAS 认为没被改过

隐患：链表操作中 A→B→A 可能导致指针出问题（如栈顶复原但中间节点被回收）

解决：版本号/时间戳

```
AtomicStampedReference<Integer> ref = new AtomicStampedReference<>(100, 0);
ref.compareAndSet(100, 200, stamp, stamp + 1);
```
