# 29. IoC 与 DI

**Q：Spring IoC 和 DI 是什么？**

IoC（控制反转）：对象的创建和管理由 Spring 容器控制，而不是开发者自己 new

DI（依赖注入）：容器将依赖对象注入到目标对象中（构造器注入、Setter 注入、字段注入）

**⚡ Q：Spring Bean 的生命周期？**

```
实例化 → 属性注入 → Aware 回调（BeanNameAware等） → BeanPostProcessor#postProcessBeforeInitialization → @PostConstruct / InitializingBean#afterPropertiesSet / init-method → BeanPostProcessor#postProcessAfterInitialization → Bean 准备就绪 → @PreDestroy / DisposableBean#destroy / destroy-method
```
